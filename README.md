# Bench Finder Project

This project is a web application that allows users to mark benches on a map and rate the benches' condition, view, and accessibility. The current initial focus area is Ankara/Çankaya, Türkiye.

## Features

- **Bench Condition Rating:** Rate the condition of the bench on a scale of 1 to 10.
- **Bench View Rating:** Rate the view from the bench on a scale of 1 to 10.
- **Accessibility Rating:** Rate the ease of access to the bench on a scale of 1 to 10.
- **Map Integration:** Integrate a map to mark and rate benches.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript, Leaflet.js for map integration.
- **Backend:** Node.js, Express.js
- **Database:** MySQL
